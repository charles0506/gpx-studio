# 🏔 { title }

本站是 [gpx.studio](https://gpx.studio) 的自架版本，針對台灣登山用途做了以下調整。

<DocsNote>
    上游的圖資與路徑規劃伺服器只接受來自 gpx.studio 的請求，因此本站全部改用公開來源：底圖 OpenFreeMap、高程與地形 Mapterhorn、路徑規劃 BRouter、興趣點 Overpass。
</DocsNote>

## 圖層

**魯地圖**（圖層選單 → 國家/地區 → 台灣）。台灣登山常用的地形圖，標示山徑、三角點、山屋與里程。另有 twmap 樣式版本可選。

## <CloudRain size="24" class="inline-block" style="margin-bottom: 5px" /> 降水雷達

地圖右側的雲雨按鈕，每點一次切換一種，循環順序為：

1. **關閉**
2. **全島整合** — 中央氣象署合成七部雷達的回波圖，涵蓋全島，每 10 分鐘更新
3. **北部（樹林）**
4. **中部（南屯）**
5. **南部（林園）**

後三者是降水雷達，各涵蓋該站周圍 150 公里，**每 90 秒更新**，適合盯著雨區逼近。一次只會顯示一個，避免影像互相重疊。

## 沿線天氣

工具列的雲朵圖示。選定軌跡後設定出發時間，按「查詢天氣」，會列出：

- 路線上每隔約 2 公里的取樣點
- 依預估步速推算的**抵達時刻**
- 該時刻的氣溫、降雨機率、雨量
- 未來 24 小時降雨長條圖與行程期間總雨量

查詢後，**海拔剖面圖下方會出現藍色降雨帶** — 沿路線任何位置都能讀到該處預估雨量，滑鼠移上去顯示數值與降雨機率。

預報來自 Open-Meteo（全球，逐小時）；台灣境內另附最近自動氣象站的即時觀測，資料來自中央氣象署。

## 預估行走時間

左下角統計面板的時間欄位。規劃中的路線沒有時間戳，此處改為顯示以 Tobler 步行函數推算的時間，前面加上 `~` 表示估算值。

計算會考慮坡度：上坡變慢、緩下坡最快。預設體能係數 0.7，反映台灣山徑有樹根、石階與拉繩的實際狀況。在「管理時間資料」工具中可調整係數，並將估算結果套用為實際時間資料。

在剖面圖上框選一段時，估算時間會跟著只計算該段。

## 離線地圖

出發前在家把路線沿線的地圖捲過、縮放看過，圖磚就會留在裝置上。山上沒有訊號時仍可開啟本站、檢視地圖與編輯路線。

程式本身也會快取，因此完全離線也能載入。

<DocsNote>
    離線快取只涵蓋你實際看過的範圍與縮放層級。出發前記得沿路線瀏覽一遍，並在你需要的縮放層級停留。
</DocsNote>

## <RefreshCw size="24" class="inline-block" style="margin-bottom: 5px" /> 同步

**檔案 → 同步**。輸入密鑰後，可將目前開啟的所有檔案上傳，或在另一台裝置下載。

提供四個獨立的使用者空間，可各自命名（名稱只存在該裝置）。四個空間共用同一組密鑰。

<DocsNote type="warning">
    上傳會覆蓋雲端內容，下載會覆蓋目前開啟的檔案，不會自動合併。下載前請先確認本機沒有尚未上傳的變更。
</DocsNote>
